**Line:** Every TODO is a note to a stranger, payable in blame.

It says the TODO you leave behind is a debt owed to whoever inherits the file, and the only currency you can pay it in is blame. It fits the brief because it is one short fortune-cookie sentence about a real developer artifact, and "payable" turns twice: a note payable is a promise to pay, and here the payment comes due at review time, in your name.

## Run it

```bash
python3 main.py
```

Writes the line to `/output/entry.txt`.
